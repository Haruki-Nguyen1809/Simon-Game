# Simon Game

A browser-based memory game built with vanilla HTML, CSS, and JavaScript (no frameworks or libraries) — a classic beginner project for practicing DOM manipulation, event handling, arrays, and `setTimeout`.

## How to Play

1. Click **Start** to begin the game.
2. Watch the sequence of colors flash on screen.
3. Click the colored squares in the same order.
4. If you match the sequence correctly, the game adds a new color and moves you to the next level.
5. If you click the wrong color, the game shows a "You lose" message and automatically restarts from level 1.
6. Click **Restart** at any time to reset the game and start over.

## Features

- Randomly generated color sequence that grows by one color each time you clear a level
- Sequential flash animation showing the current sequence, with each color lit up in order
- Click-to-play input using the same 4 color buttons
- Win/lose detection with automatic level progression or reset
- Manual restart button, independent of winning or losing
- Simple dark theme styling with a glowing flash effect on active buttons

## Project Structure

```
├── index.html      # Page structure: title, level text, 4 color buttons, Start/Restart buttons
├── index.js        # Game logic: random color generation, flashing sequence, click handling, win/lose logic
└── style.css       # Styling: layout, colors, flash animation, button design
```

## Core Logic Overview

- **`buttonColor`** — fixed array of the 4 available colors (`red`, `blue`, `green`, `yellow`), matching each div's `id`.
- **`randomButtonColor`** — accumulates the full sequence of colors generated by the game so far. Grows by one color per level; never resets except on loss or restart.
- **`playerChoose`** — stores the colors the player has clicked so far in the current attempt. Reset after each successful level or loss.
- **`randomColor()`** — generates a random index (`0`–`3`), picks the corresponding color, pushes it into `randomButtonColor`, and returns that color.
- **`makeflash()`** — loops through `randomButtonColor` and uses `setTimeout` to flash each color in order, spaced out over time (rather than all at once), by scheduling the `add` and `remove` of the `.flash` class at staggered timestamps.
- **Click handling** — on each color click, the clicked color is pushed to `playerChoose`, then compared against `randomButtonColor` at the same index to check correctness, and against the sequence length to detect a completed level.

## What This Project Practices

- DOM selection and manipulation (`getElementById`, `querySelectorAll`, `classList`)
- Event listeners and the `this` keyword inside callbacks
- Array methods (`push`, `.length`, indexing)
- `setTimeout` and timing/staggering logic inside loops
- Conditional logic for win/lose state management
- Function design: single-responsibility functions, `return` values, and reusability
